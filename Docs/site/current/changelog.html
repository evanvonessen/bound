Bound changelog

October 22, 2026

Bound

  • Stop in Friends fully disconnects sharing until you select a friend again.
  • Receive Notifications replaces Receive Jiggles; friend alerts now say who wants to play Pokémon.
  • Standardized settings headings and removed the Radical Red header from Controls.
  • Removed passkey controls and availability messages from account settings and sign-in on iPhone, iPad and Mac.
  • Mac's workspace menu can show or hide Friend Gameplay and Multiview independently.
  • Friends and Account and Security use consistent layouts across both UI versions and Mac, with the friend list above multiplayer controls.
  • Live friend video no longer briefly hides when a decoded frame arrives between display updates.
  • Mac consistently uses the updated Friends and Account and Security menus, including with older saved iPhone UI preferences.
  • Account changes and security controls share one Account and Security menu; Add friend now sits beside the Friends heading.
  • Change your username directly from the Friends tile.
  • A visible Change email control in account settings, Account security and the companion panel.

Radical Red multiplayer

  • The new-game settings chooser can enable Woyaopp, SO2Toxic, DexAll, TeamPreview and EZCatch together with a Yes or No choice.
  • Player State Display now hides immediately when Developer Features is turned off.
  • Oak offers new-game Soul Link pairing with your Bound friends, shared native options and separate saved randomization seeds.
  • In-game friend menus open multiplayer actions, partner video and the run timeline; background services start automatically.
  • Native disconnect and recovery dialogue pauses battles and scripts until the linked run can safely continue.
  • Paired checkpoints, local recovery snapshots and complete Dropbox save packages preserve each player's progress.
  • Device ownership and saved-history checks protect linked runs from conflicting devices and older saves.
  • Moved multiplayer diagnostics and duplicate gameplay controls behind Enable Developer Features.
  • Renamed the opt-in switch to Enable Experimental Multiplayer.
  • Friend video and spectating hide stalled frames and wait for fresh decoded video after reconnection.
  • A saved run timeline for new Pokémon acquisitions, linked deaths, completed trades and battle victories, with event filters.

October 21, 2026

Radical Red multiplayer

  • Watch your partner’s battles live in a dedicated full-screen view.
  • Native in-game menus for battle and trade invitations.
  • Persistent Pokémon trades with native party selection and animations.
  • Trade recovery after disconnects, interruptions and app restarts.
  • Soul Link invitations for fresh two-player runs.
  • Automatic encounter pairing by area, with eggs paired in acquisition order.
  • A searchable paired encounter list showing both players’ catches and status.
  • A shared Soul Link team dashboard with both parties, sprites, levels, HP and party/box status.
  • Permanent linked fainting, including boxed Pokémon and healing restrictions.
  • Soul Link death notifications and a graveyard of lost pairs.
  • Saved Soul Link history with reconnect, resume and end-run controls.
  • Shared trainer progression requiring both players to clear earlier battles.
  • Shared gates for badges, flag-controlled obstacles, Cut, Rock Smash and Strength.
  • Automatic trainer encounters respect shared progress and show a native wait dialogue.
  • Support for the integrated Radical Red multiplayer ROM and matching Bound app.

Bound

  • A single Game Boy Advance library page.
  • Changelog in About settings and on the website.
  • Account-linked Dropbox sync across devices.
  • Password recovery, email changes and optional authenticator security.
  • Metal rendering by default, with renderer choices in regular settings.
