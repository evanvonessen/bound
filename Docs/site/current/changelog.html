Bound changelog

October 24, 2026

Bound

  • Friends show Connected when both players are online. Inactive rows have no highlight, and Stop clears the connection and highlight.

Radical Red multiplayer

  • Choose server saves or set up a new shared run in Bound. Friends can join later; fresh games start directly in the bedroom.
  • Multiplayer progress now uses permanent shared server saves with separate player checkpoints, automatic saving and confirmed deletion for both players.
  • Offscreen friends show a direction arrow, name and tile distance; position tracking continues outside the camera view.
  • One player chooses the shared setup; each player then progresses, saves and resumes independently, including while their partner is offline.
  • New Game offers Debug mode: Gary, Minimal Grind, default randomizers, all five common cheats and nickname prompts off, then an automatic bedroom start.
  • Shared Soul Link events retry in the background; older saves preserve permanent losses, and partner avatars no longer block movement.
  • Select each other in the ROM setup to connect automatically, without opening Friends. Improved setup restart and connection recovery.

October 23, 2026

Bound

  • Fixed Add Friend closing Settings. The Settings footer now shows the installed Bound build number.
  • Approved accounts can back up and restore game saves on the Bound server. Cloud Backups selects one provider: Dropbox or Server Backups.
  • The bundled Multi Red ROM shows the app build number in its library name.
  • Long-press a ROM to clear its cartridge saves, save states, Dropbox saves, and save conflicts after confirmation. The ROM stays locked until cleanup finishes.
  • New builds use the Bound account server. Sign in again with your existing password and reconnect Dropbox.

Radical Red multiplayer

  • Friends stay visible during brief stalls and reconnects. Nakama keeps persistent run state and coordinates both players’ manual saves.
  • Removed timed and gameplay-event autosaves from multiplayer. Saving starts from the in-game Save action.
  • Multiplayer menus stay visible when changing selections or paging through friends.
  • The doubles version lets friends share existing double battles, including battles with an NPC partner, with the original opponent teams.
  • Soft resets preserve linked-run recovery, and recovery menus stay visible during screen fades.
  • Cancelled pairing returns to setup. Completed-checkpoint recovery restores matching saves while preserving newer run history.
  • Improved recovery after interrupted synchronization, restores, and device transfers. Handoff waits until native battles and trades finish.

October 22, 2026

Bound

  • iPhone and Mac builds include their matching Multi Red ROM and add it to the library automatically, keeping older ROMs and saves.
  • Manage Save File now offers Clear Saves for one ROM, with confirmation.
  • Added support for a separately configured account server.
  • Automatic iCloud ROM updates on iPhone and Mac back up and reset saves when the integrated ROM changes.
  • Debugging Features adds optional GitHub sign-in on iPhone and Mac.
  • Friends, Refresh and Add are now available in Account, Friends, & Sync, with a signed-in username footer.
  • On Mac, the Multiview controller button switches between sidebar navigation and gameplay without hiding the sidebar.
  • Mac sidebar Disconnect now stays disconnected until you select a friend again, matching iPhone Friends.
  • Stop in Friends fully disconnects sharing until you select a friend again.
  • Receive Notifications replaces Receive Jiggles; friend alerts now say who wants to play Pokémon.
  • Standardized settings headings and removed the Radical Red header from Controls.
  • Removed passkey controls and availability messages from account settings and sign-in on iPhone, iPad and Mac.
  • Mac's workspace menu can show or hide Friend Gameplay and Multiview independently.
  • Friends and Account and Security use consistent layouts across both UI versions and Mac, with the friend list above multiplayer controls.
  • Live friend video no longer briefly hides when a decoded frame arrives between display updates.
  • Mac consistently uses the updated Friends and Account and Security menus, including with older saved iPhone UI preferences.
  • Account changes and security controls share one Account and Security menu; Add friend now sits beside the Friends heading.
  • Change your username directly from the Friends tile.
  • A visible Change email control in account settings, Account security and the companion panel.

Radical Red multiplayer

  • New Game in recovery ends the previous Soul Link and returns to setup while preserving its saves and recovery files.
  • Completed the separation of multiplayer data and Friends video.
  • Added Nakama gameplay connections with separate partner video.
  • ROM-started multiplayer connects without starting video capture.
  • Friends stay visible during dialogue and brief connection gaps.
  • Players cannot walk through friends, but can walk apart after spawning on the same tile.
  • Paired saves wait for both players to be safely stopped and cancel unavailable attempts.
  • The shared setup chooser names the rival for both players.
  • Refresh in the in-game Friends list loads friends added after the game started.
  • Friendly battles started through a nearby friend do not cause permanent Soul Link losses.
  • After choosing common cheats, new-game setup can open the nickname screen automatically for catches, gifts and hatched Pokémon.
  • The new-game settings chooser can enable Woyaopp, SO2Toxic, DexAll, TeamPreview and EZCatch together with a Yes or No choice.
  • Player State Display now hides immediately when Developer Features is turned off.
  • Oak offers new-game Soul Link pairing with your Bound friends, shared native options and separate saved randomization seeds.
  • In-game friend menus open multiplayer actions, partner video and the run timeline; background services start automatically.
  • Native disconnect and recovery dialogue pauses battles and scripts until the linked run can safely continue.
  • Paired checkpoints, local recovery snapshots and complete Dropbox save packages preserve each player's progress.
  • Device ownership and saved-history checks protect linked runs from conflicting devices and older saves.
  • Moved multiplayer diagnostics and duplicate gameplay controls behind Enable Developer Features.
  • Renamed the opt-in switch to Enable Experimental Multiplayer.
  • Friend video and spectating hide stalled frames and wait for fresh decoded video after reconnection.
  • A saved run timeline for new Pokémon acquisitions, linked deaths, completed trades and battle victories, with event filters.
