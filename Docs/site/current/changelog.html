Bound

  • Screen-share retries find the selected cartridge partner, revalidate account ownership, and preserve the gameplay connection without another friend notification.

Radical Red multiplayer

  • Friend sprites use the emulator’s displayed palette, including nighttime colors.

Radical Red multiplayer

  • Joining a ROM server automatically connects multiplayer and retries interruptions while that server remains selected. Friends shows multiplayer status without a separate connect or disconnect button; Screen Share remains independent.

October 26, 2026

Bound

  • Added Clear ROMs in main Settings. Review one exact cleanup scope before permanently removing recognized older cartridges and their saves; the current bundled ROM and unrelated games are preserved. Interrupted cloud deletion remains available for retry.
  • History multiview now contains Connections for Debug Mode games and Run Timeline for Enable Developer Tools. Connection events retain each friend's username and distinguish Screen Share from Multiplayer.
  • Removed the DEBUG statepoints tab from multiview navigation while preserving the unfinished implementation for future work.
  • Screen sharing appears only in Friends multiview beside the playable local game. Removed full-screen Watch Partner; hidden panels clear video presentation while the independent sharing session stays connected.
  • Friends now have independent Screen Share and Multiplayer buttons, each with its own connection status. Stopping video leaves gameplay connected; multiplayer disconnect preserves interrupted activities for recovery.
  • Combined developer switches into Enable Developer Tools, preserving either previous opt-in and keeping Export All Config under that preference.
  • Removed GitHub sign-in and ROM Updates settings. Matching bundled ROM installation, backups and interrupted-update recovery remain available.

Radical Red multiplayer

  • Fixed restoring interrupted native battles after the game's allocator resets, while preserving exact ROM compatibility checks and existing field saves.
  • Pre-offer trade cancellation restores the original party and checkpoint. Invalid native storage records no longer become Soul Link acquisitions.
  • Removed the standalone in-game multiplayer menu and run-history entry points. Walk up to a friend and interact to Battle or Trade; run setup stays in Bound.
  • Restored native R behavior and the default right-trigger Start binding, preserving customized controls. Removed the Debug R return warp.
  • New Debug Mode games use Easy difficulty and enable Game Over on Party Wipe. Infinite Repel is unlocked in the original L-button skills menu and starts off.
  • Fixed competing battle-completion hooks in the experimental combined cooperative cartridge and kept friendly menus out of cooperative recovery memory.
  • Pending battle and trade invitations keep gameplay running. Open the notification to review, or cancel it; unanswered requests expire safely.
  • Fixed early A/B presses being ignored while native invitation menus were becoming ready.
  • Reduced repeated Soul Link storage copying and fixed restored event histories with adjacent receipt gaps.
  • Moved Soul Link record processing off the frame callback, with a paused Retry flow that preserves pending changes when saving fails.
  • Added session-scoped paired DEBUG controls for local testing, including reload, custom capture, return to ordinary runs and sanitized reports. Progression statepoints remain disabled until their validation is complete.
  • Fixed DEBUG checkpoint conflicts during paired readiness and retries after lost save replies.
  • Kept DEBUG restore and Return to Previous Run tied to their original ROM profile when the current test cartridge changes.
  • Final saves wait for pending history and uploads. Failed preparation keeps the paused run available for Retry, including after signing back in.
  • Fixed checkpoint capture repeatedly scheduling another save. DEBUG Return retries refresh confirmation without rewinding ordinary play.
  • DEBUG restore rechecks the stopped game before holding it for a switch, allowing an unchanged run to resume when that boundary is temporarily unsafe.
  • Each release includes its matching multiplayer.gba and installs it automatically while preserving older cartridges and saves.
