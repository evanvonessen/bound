Start with your own games

  1. Open Bound’s Library and tap + to import a compatible game file from Files.
  2. Open the imported game to play. No Bound account is required for local gameplay.
  3. Open the native pause menu for Bound Settings, layout choices and controls. The companion button cycles Friends, Notes and Types.

Bound contains no games and does not provide downloads. Only import files you have permission to use. Some systems need additional files supplied by you.

Bound is in development for iPhone, with iOS 17 or later. This page is not an App Store download or an invitation to TestFlight.

A few useful answers

My file won’t import.

Check that it is a supported game file and that the Files provider has downloaded it locally. Try importing the ordinary file directly. Renaming an unsupported file’s extension will not make it compatible. Tell support the file extension and provider, without attaching the game.

How do Notes and Types work?

The companion button cycles through the friend view, per-game notes and type chart. Notes are saved locally; editing pauses local gameplay. Finishing the edit resumes gameplay when the game can safely resume.

How do I share with a friend?

From the pause menu, open Connect or Friends and sign in with your existing Bound account. Select a friend or exchange an invite, then start sharing. You each play independently. Sharing sends game video, without a camera or microphone stream.

Stop sharing to disconnect. Returning to Library, changing games, signing out or backgrounding Bound also stops the session. You must explicitly start again after returning.

Are my notes or games sent to my friend?

The friend feature sends game video and account/session information. It does not send your notes or game files. Any personal information visible inside the game can appear in its video.

Optional Google Drive or Dropbox sync is a separate inherited feature. If enabled, it can transfer game files, saves and other selected library records to your chosen service. See privacy details.

How do I request account or data deletion?

Email developer@evanvonessen.com with your request. The current Delta-based version does not include the older Bound app’s account-deletion screen. Signing out removes the saved local session; it does not delete the service account or remotely stored information.

Will changing the layout change my emulator?

No. Classic and Bound change the arrangement of the game, controls and companion panel. Emulation continues through the native Delta core.

Community rules and safety

Read the community rules, report/block guidance, and moderation policy. Stop sharing and contact support if your build lacks the new controls.
