# Independent friend connections

Joining or reopening a ROM server automatically requests its authenticated multiplayer connection and enables friend presence. The request retries interruptions while that server remains selected, including after backgrounding. Friends and Account, Friends, & Sync show the selected partner's multiplayer status without a separate connect/disconnect button. The Mac friend panel uses the same row. Connected requires the expected peer to be present; a local server join alone does not claim that the friend is online. Sprite presentation still requires compatible ROMs, fresh valid positions and a visible map area.

Screen Share keeps its independent button and Agora session, authorization renewal, frame capture and presentation. Multiplayer owns the existing Nakama room, Soul Link, native activities and recovery. Screen Share off stops only video; it cannot disconnect the selected ROM server or cancel its retries. Video may target another listed friend without changing the run's partner. Opening Friends or selecting video alone never selects a multiplayer server.

Leaving the ROM server stops its connection request and pending retries through the existing run lifecycle. Interrupted native activities, authenticated ownership and server saves retain their existing recovery rules. Sign-out, account replacement, removal or blocking revokes the affected ownership scope. Existing invitation expiry and revalidation rules still apply. Re-enabling video sends the existing explicit-share Jiggle; multiplayer never sends one.

The Experimental Multiplayer preference remains required and default off. Game Debug Mode and developer tools remain separate. ROM bytes, exact profiles, save formats, statepoints and backend behavior are unchanged.

Validation uses injected Agora events and a real Nakama client with an isolated socket fixture for automatic server connection, independent video controls and failures, stale callbacks, consent preservation, reconnect backoff, background restoration and cancellation on leaving the server. Hosted phone/Mac views and account lifecycle tests cover both UI surfaces. These checks do not certify physical-device, live Agora/Nakama, WAN or unfinished statepoint behavior.
