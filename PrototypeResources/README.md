# Bundled FireRed cover

`firered-cover.png` is the original North American Pokémon FireRed GBA cover,
used for the bundled cartridge's library entry. The build copies it alongside
`multiplayer.gba`; installation copies it into the library for offline display.
Existing user-selected artwork is retained.
