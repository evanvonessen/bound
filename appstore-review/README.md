# Bound App Review files

These files accompany the review demonstration for Bound version 1.0, build 12.

- [Download the physical-device recording](https://media.githubusercontent.com/media/evanvonessen/bound/main/appstore-review/recording_demo.mp4)
- [Download 2048.gba](https://raw.githubusercontent.com/evanvonessen/bound/main/appstore-review/2048.gba)

The recording is the smaller desktop copy supplied for review, captured on an iPhone 17 Pro Max running iOS 27.0.1. Its full duration and audio are retained. The video is stored using Git LFS; the download link above serves the MP4 itself.

## Demo game

2048 Advance v1.3.1 by Basil Termini. The ROM is unchanged from the creator's download.
